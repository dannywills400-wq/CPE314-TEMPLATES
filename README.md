## Project Description

This project is a simple To-Do List web application developed as part of **Lab 8** for the Front-End Web Development course. It demonstrates the integration of HTML, CSS, and JavaScript to build an interactive web application.

---

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Automatically save tasks using Local Storage
- Responsive layout for desktop and mobile devices

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

---

## Project Structure

```text
todo.html
todo.css
todo.js
README.md
```

---

## How to Run

1. Download or clone the repository.
2. Open `todo.html` in any modern web browser.
3. Add, complete, and delete tasks.
4. Refresh the page to verify that tasks are preserved using Local Storage.

---

## Learning Outcomes

This project demonstrates:

- HTML page structure
- CSS styling and responsive design
- JavaScript DOM manipulation
- Event handling
- Local Storage for persistent data
- Front-end application integration
